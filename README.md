# Ethics and Environmental Impact of EV & AV

A six-page static website (HTML, CSS, a little JavaScript). No install or build step.

Files: `index.html`, `evav.html`, `impact.html`, `issues.html`, `solutions.html`, `sources.html`, `style.css`, `script.js`, and the `images` folder.

## Publish on GitHub Pages
1. Create a GitHub account and click **New repository** (e.g. `avev`, Public).
2. Click **uploading an existing file** and drag in ALL files AND the `images` folder (keep the same layout), then **Commit changes**.
3. Go to **Settings > Pages**, choose branch `main` and `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/avev/`.
